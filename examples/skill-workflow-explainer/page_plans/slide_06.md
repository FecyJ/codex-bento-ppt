# slide_06 - 便利贴与策划稿：设计前先冻结意图

## Page Role

Planning.

## Core Message

每页先是可移动的 sticky note，再成为给设计师的策划稿。

## Content Blocks

1. Sticky note fields: role, title, message, evidence, audience value, visual intent.
2. Page plan fields: content blocks, designer handoff draft, Bento layout plan, visual direction.
3. Benefit: user can review story before design polish.

## Designer Handoff Draft

- Plain wireframe intent: left sticky note wall; right wireframe page plan.
- Exact element placement: sticky notes as smaller cards; wireframe plan as large pale card.
- What must be emphasized: design intent frozen before SVG.
- What may be omitted if crowded: full field list.
- What should stay visually quiet: secondary labels.

## Evidence To Show

- `prompts/03-outline-architect.md`
- `prompts/04-page-planner.md`

## Bento Layout Plan

- Canvas: 1280x720
- Grid: two-column planning contrast
- Card A: x=72, y=150, w=500, h=430, purpose=sticky notes
- Card B: x=604, y=150, w=604, h=430, purpose=page planning draft
- Card C: x=72, y=604, w=1136, h=62, purpose=quality statement
- Gutters: at least 20px

## Visual Direction

- palette: use a lighter wireframe card inside dark deck
- typography: Noto Sans CJK SC stack
- icon/image needs: sticky note shapes, wireframe blocks
- avoid: over-polishing the planning draft
- reference image/style cue: article planning-draft screenshots
